인포러시

주제를 붙여넣으면 AI가 품질 기준을 지킨 정보성 글과 썸네일을 만들어 네이버 블로그에 임시저장합니다.

모델 확인 중 AI 확인 중 브라우저 확인 중 로그인 확인 중

1. 네이버 로그인

로그인 세션은 이 컴퓨터에만 저장됩니다.

[네이버 로그인 창 열기] 를 누르면 진짜 브라우저 창이 뜹니다. 아이디와 비밀번호는 그 창에 직접 입력하세요. 2단계 인증도 그대로 하시면 됩니다. 이 프로그램은 아이디와 비밀번호를 받지도, 저장하지도 않습니다.
로그인이 확인되면 세션이 data/browser-profile/ 에 저장되어 다음부터는 다시 로그인할 필요가 없습니다. 블로그 아이디는 자동으로 찾지만, 못 찾으면 위 칸에 직접 넣어 주세요.

2. 주제 붙여넣기

0개 인식

주제에 TOP 5, 7가지 처럼 개수가 들어 있으면 항목마다 상세 설명 · 자격 요건 · 활용 분야 · 장단점 · 준비 팁을 세부 소제목으로 나눠 씁니다. 개수가 12개를 넘으면 큰 비교표를 나눠서 만들고 대표 항목만 상세하게 다룹니다.

3. AI에게 줄 지침 & 참고 예시

필수 품질 규칙은 자동으로 들어갑니다

입력 후 자동으로 저장됩니다. 여기 쓴 내용은 프롬프트 맨 앞과 맨 끝에 두 번 들어갑니다. 다만 필수 준수 규칙(분량·문체·표·구조)은 지침보다 우선합니다. 그래야 이 프로그램의 목적인 "검색에 걸리는 정보성 글"이 유지됩니다.

참고 예시 글

0개

"이런 식으로 써줘" 하고 보여줄 글을 올리면 문체와 구성을 참고합니다. txt / md / html / csv 파일을 올리거나 아래에 직접 붙여넣으세요. (내용을 베끼지는 않습니다)

    4. 자료 조사 (웹 검색)

    글을 쓰기 전에 최신 자료를 검색해 근거로 씁니다

    조사와 집필을 두 번의 호출로 나눠서 합니다. 먼저 검색으로 사실과 출처만 모으고, 그다음 검색을 끄고 그 자료만 보고 글을 씁니다. 한 번에 시키면 검색 결과를 설명하는 말이 섞여 들어와 결과가 자주 깨집니다.
    모아온 자료는 research.json 으로 남고, 미리보기 맨 위에 검색 횟수와 확인하지 못한 내용이 표시됩니다. 발행 전에 그 부분을 꼭 확인하세요.

    5. 정보성 글 품질 규칙

    모든 글이 이 검사를 통과해야 저장됩니다
